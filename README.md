# GitHub Pages: ссылки на CaseBattle

Эта ветка содержит только страницы перенаправления. Серверный сайт и админка работают в Sites; GitHub Pages служит короткой ссылкой-входом, адрес в браузере после перехода меняется.

В Settings → Pages выберите Deploy from a branch → gh-pages → / (root) → Save.

После успешной публикации GitHub Pages предполагаемые адреса:
- https://west1kexe.github.io/casebatte/
- https://west1kexe.github.io/casebatte/admin/

Пока Pages не включён и публикация не завершена, эти адреса не считаются работающими. В GitHub Free Pages требует публичный репозиторий; частный поддерживается платными подходящими планами. Открытие репозитория публикует также его исходники и историю — это отдельное решение владельца.
